# Civic Pulse - Telugu AI Government Scheme Assistant

Track 1 (Civic Pulse) entry for IDEA FORGE. A Telugu-first web app that helps citizens discover government schemes, check documents and learn how to apply.

## Features
Telugu/English toggle, profile-based scheme matching, search and category filters, scheme details with a tickable document checklist, step-by-step apply guide with official links, bookmarks (localStorage) and a demo AI chat assistant.

## Run (Windows)
1. Install Node.js LTS from https://nodejs.org
2. Open PowerShell in this folder, then run:
   `npm install`
   `npm run dev`
3. Open http://localhost:5173

## Honesty note
All scheme text is general SAMPLE data and is labelled "not verified". Users are told to confirm rules, amounts and documents on the official portal. The chatbot is a keyword-based DEMO over this data; no AI key is needed.

## Roadmap
Real LLM (Claude API) behind a small backend, verified scheme database with dates, more AP/Telangana schemes, voice input, WhatsApp bot.
